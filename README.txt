ASTROLOGIE ORION – Projet final Développement Web 1

Fichiers principaux:
- index.html : page d'accueil
- zodiaque.html : signes, dates, caractéristiques et traits
- astrologie.html : informations générales et liens externes
- horoscope.html : formulaire demandé dans le projet
- contact.html : contact par courriel
- style.css : styles CSS communs
- images/ : logo, illustration d'accueil et 12 symboles zodiacaux
- PLANIFICATION.txt : plan de conception

Pour tester:
1. Décompresser le dossier.
2. Ouvrir index.html dans un navigateur.
3. Naviguer avec le menu.

Technologies: HTML5 + CSS3 + SVG.
Le formulaire n'est volontairement pas fonctionnel, conformément aux consignes du PDF.
